Implement the function `int64_t fib_rec(int64_t n)`.

Target: AArch64 (ARMv8-A), Linux AAPCS64. Integer/pointer arguments in x0-x7; 64-bit result in x0. Callee-saved: x19-x28, x29 (frame pointer) and d8-d15 (restore them if you use them); x9-x15 are free scratch registers. sp must stay 16-byte aligned and be back to its entry value when you return with ret (return address in x30). More ABI facts: arguments beyond the eighth are passed on the stack (the 9th at [sp] at entry). A call (bl/blr) overwrites x30, so save x30 (e.g. stp x29, x30, [sp, #-16]!) before calling and restore it before ret. A call clobbers the caller-saved registers x0-x18, x30, v0-v7 and v16-v31 (and the upper halves of v8-v15) and the flags, so keep values that must survive a call in callee-saved registers x19-x28 (saved/restored by you) or in your own stack frame. sp must be 16-byte aligned at every call (and whenever it is used as a base register). Anything below sp may be overwritten by a callee.

Output format: QBE intermediate language (the IL of the QBE compiler backend, c9x.me/compile). Write exactly one function, `export function l $fib_rec(...)`, taking every argument as `l` (64-bit; pointers are `l` too) and returning `l`. QBE will compile it for the target above, so you do not handle registers or the ABI yourself. Remember: every block starts with an `@label`; temporaries are `%name`; comparisons such as `csltl`/`ceql` produce a `w` value; `jnz` tests a `w`; loads/stores are `loadl`/`storel`. No data definitions and no other functions; the only calls are to $fib_rec itself. Output only the QBE code: no Markdown fences, no prose. Call the function itself with `%r =l call $fib_rec(l %x)`.

Specification: Return the n-th Fibonacci number: fib_rec(0) = 0, fib_rec(1) = 1, and for n >= 2 fib_rec(n) = fib_rec(n-1) + fib_rec(n-2). 0 <= n <= 20. The implementation MUST be the naive doubly recursive one: for n >= 2 the function calls itself twice, with a real call instruction to its own entry point, and adds the two results (no loop, no memoisation; the machine code is checked for a call to its own entry). Every recursive call is a normal ABI call and is checked as one: the stack must be 16-byte aligned at each call, and any callee-saved register you use must be saved and restored.
