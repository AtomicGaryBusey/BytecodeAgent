Implement the function `int64_t map_into(int64_t *dst, const int64_t *src, int64_t n, int64_t (*f)(int64_t))`.

Target: AArch64 (ARMv8-A), Linux AAPCS64. Integer/pointer arguments in x0-x7; 64-bit result in x0. Callee-saved: x19-x28, x29 (frame pointer) and d8-d15 (restore them if you use them); x9-x15 are free scratch registers. sp must stay 16-byte aligned and be back to its entry value when you return with ret (return address in x30). More ABI facts: arguments beyond the eighth are passed on the stack (the 9th at [sp] at entry). A call (bl/blr) overwrites x30, so save x30 (e.g. stp x29, x30, [sp, #-16]!) before calling and restore it before ret. A call clobbers the caller-saved registers x0-x18, x30, v0-v7 and v16-v31 (and the upper halves of v8-v15) and the flags, so keep values that must survive a call in callee-saved registers x19-x28 (saved/restored by you) or in your own stack frame. sp must be 16-byte aligned at every call (and whenever it is used as a base register). Anything below sp may be overwritten by a callee.

Output format: GNU assembler syntax for AArch64, e.g. `ldr x2, [x0, x1, lsl #3]`. Output ONLY the function's instructions and labels, one per line, starting with the label `map_into:` (the entry point). Labels are `name:` (letters, digits, _ and ., e.g. `.Lloop:`); every branch target (b, b.cond, cbz, cbnz, tbz, tbnz, bl, adr) must be a label, never a number. Comments start with `//`; do not use `;`. No directives of any kind (no .section/.align/.word/.quad), no literal pools (`ldr x0, =...`), no data, the only call is through the function-pointer argument (e.g. `blr x19`). Each line under 120 characters. No Markdown fences, no prose before or after the code. Instruction set: ARMv8.0-A with floating point and Advanced SIMD (NEON). Not supported (rejected): CRC32, LSE atomics, dot product, half-precision, crypto (AES/SHA/PMULL) and SVE.

Specification: src and dst each point to n signed 64-bit integers (0 <= n <= 64; the two arrays do not overlap). f points to a function `int64_t f(int64_t)` that follows the same ABI. For i = 0 .. n-1, in order, set dst[i] = f(src[i]), calling f exactly once per element. Return the number of indices i for which dst[i] < src[i] (signed comparison); 0 when n = 0. f is opaque (you do not know what it computes); it may clobber every caller-saved register, the flags and the stack below the stack pointer, and it checks that the stack is 16-byte aligned at each call. Read only src[0..n-1] and dst[0..n-1], and write only dst[0..n-1] (both are checked).
