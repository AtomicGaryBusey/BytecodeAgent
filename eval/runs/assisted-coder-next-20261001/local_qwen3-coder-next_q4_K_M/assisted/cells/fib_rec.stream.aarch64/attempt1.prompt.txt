A call (bl/blr) overwrites x30, so save x30 (e.g. stp x29, x30, [sp, #-16]!) before calling and restore it before ret. A call clobbers the caller-saved registers x0-x18, x30, v0-v7 and v16-v31 (and the upper halves of v8-v15) and the flags, so keep values that must survive a call in callee-saved registers x19-x28 (saved/restored by you) or in your own stack frame. sp must be 16-byte aligned at every call (and whenever it is used as a base register). Specification: Return the n-th Fibonacci number: fib_rec(0) = 0, fib_rec(1) = 1, and for n >= 2 fib_rec(n) = fib_rec(n-1) + fib_rec(n-2). 0 <= n <= 20. The implementation MUST be the naive doubly recursive one: for n >= 2 the function calls itself twice, with a real call instruction to its own entry point, and adds the two results (no loop, no memoisation; the machine code is checked for a call to its own entry). Notes (to help you avoid common mistakes):
AArch64 constants: `mov xN, #imm` only encodes a 16-bit value shifted by 0, 16, 32 or 48 (or its bitwise inverse, or a logical bitmask). Build any other constant 16 bits at a time: `movz x9, #0x5678` then `movk x9, #0x1234, lsl #16` gives 0x12345678 (add `movk ..., lsl #32` / `lsl #48` for wider values).
