Implement the function `int64_t reverse(int64_t *a, int64_t n)`.

Target: x86-64, Linux System V ABI. Integer/pointer arguments in rdi, rsi, rdx, rcx, r8, r9; 64-bit result in rax. Callee-saved: rbx, rbp, r12, r13, r14, r15 (restore them if you use them); all other registers may be clobbered. rsp is 16-byte aligned before the call, so it is 8 mod 16 at entry; it must be back to its entry value when you return with ret. Never write to the caller's frame (at or above the return address).

Output format: GNU assembler syntax, Intel flavour without register prefixes (as with `.intel_syntax noprefix`), e.g. `mov rax, qword ptr [rdi + rcx*8]`. Output ONLY the function's instructions and labels, one per line, starting with the label `reverse:` (the entry point). Labels are `name:` (letters, digits, _ and ., e.g. `.Lloop:`); every branch target must be a label, never a number. Comments start with `#`; do not use `;`. No directives of any kind (no .section/.align/.byte/.quad/.p2align), no data, no calls to other functions. Each line under 120 characters. No Markdown fences, no prose before or after the code.

Specification: a points to n signed 64-bit integers, n >= 0. Reverse the array in place (a[0] swaps with a[n-1], and so on) and return 0. Write nothing outside a[0..n-1].
