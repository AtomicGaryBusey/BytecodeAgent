Notes (to help you avoid common mistakes):
AArch64 constants: `mov xN, #imm` only encodes a 16-bit value shifted by 0, 16, 32 or 48 (or its bitwise inverse, or a logical bitmask). Build any other constant 16 bits at a time: `movz x9, #0x5678` then `movk x9, #0x1234, lsl #16` gives 0x12345678 (add `movk ..., lsl #32` / `lsl #48` for wider values).
