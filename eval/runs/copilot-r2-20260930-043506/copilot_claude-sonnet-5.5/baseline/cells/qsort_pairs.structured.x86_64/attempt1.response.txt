Design: Lomuto partition with the last record as pivot, using a signed lexicographic compare.

Registers: rbx = a, r12 = n, r13 = i (store index), r14 = j, r15 = pivot key, rbp = pivot value.

Prologue: push rbx, r12, r13, r14, r15, rbp. That is 6 pushes, so rsp is 8 mod 16 + 48 = 8 mod 16 (entry 8 mod 16, minus 48 gives 8 mod 16). I need 0 mod 16 at the call, so I add sub rsp, 8.

Algorithm:
- If n < 2, return 0.
- Pivot = record n-1: r14 = n-1, then shl 4 to get the byte offset. Load the pivot key into r15 and value into rbp.
- i = 0, j = 0. Loop while j < n-1:
  - Record j is at rbx + j*16. Compute rax = j<<4 and add rbx.
  - Less than the pivot if key < pk, or key == pk and val < pv.
  - If so, swap record i with record j and increment i.
  - Increment j.
- After the loop, swap record i with record n-1 (the pivot).
- Recurse on the left part (a, i). Then the right part is (a+(i+1)*16, n-i-1). Both are recursive calls, and I keep n-1 in r12 so the calls stay simple.

Registers across the calls: after the partition, r13 = i. Left call: rdi = rbx, rsi = r13. Right call: rdi = rbx + (r13+1)*16, rsi = r12 - r13 - 1.

Swap helper, inline: rax = address of record i, rdx = address of record j. Load the four values into rcx, rsi, rdi, r8 and store them crosswise.

The stores are in the loop, so I use r9 for the address of record j and r10 for the address of record i.

The compare uses r9 = address of record j: rcx = [r9], then cmp rcx, r15; jl swap; jg skip; rcx = [r9+8]; cmp rcx, rbp; jge skip.

I use r12 = n and r14 = j, with the loop bound n-1 computed by comparing j against r12-1 through a temporary in rax.
