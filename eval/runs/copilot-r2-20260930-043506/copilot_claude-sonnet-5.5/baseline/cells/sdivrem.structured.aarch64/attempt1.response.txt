AArch64 `sdiv` already gives the required results for both special cases:
- b == 0: sdiv returns 0, so q = 0, and r = a - 0*b = a.
- INT64_MIN / -1: sdiv returns INT64_MIN with no trap, so r = a - q*b = INT64_MIN - (INT64_MIN * -1). The product wraps to INT64_MIN, so r = 0.

The general case is q = sdiv(a, b) and r = msub(q, b, a), which computes a - q*b.
