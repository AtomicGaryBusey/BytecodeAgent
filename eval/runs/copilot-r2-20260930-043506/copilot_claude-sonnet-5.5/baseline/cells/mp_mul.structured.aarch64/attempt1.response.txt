Plan: zero r[0..na+nb-1], then for each i in a, do a row of multiply-accumulate, and finally count the significant limbs.

Registers: x0=a, x1=na, x2=b, x3=nb, x4=r.

Setup: n = na+nb in x5. If n == 0, return 0 (this also covers na or nb equal to 0).

Zero loop: x6=0 counter; str xzr,[x4,x6,lsl 3]; add x6,x6,1; cmp x6,x5; b.lo.

If na == 0 or nb == 0, r is already zeroed, so return 0 via the n==0 check plus a separate check. For n>0 with one of them 0, the outer loop simply never runs (na==0) or the inner loop must not run (nb==0). I handle nb==0 by branching to the count section, which is fine because r is all zero.

Outer loop, i in x6 from 0 to na-1:
- x7 = a[i]; x9 = carry = 0; j in x10 = 0.
- Inner loop, while j < nb:
  - x11 = b[j]
  - x12 = mul(x7,x11); x13 = umulh(x7,x11)
  - x14 = r[i+j]; the address is x4 + (x6+x10)*8, so I compute x15 = x6+x10 and use it as the index.
  - adds x12,x12,x9 ; cinc x13,x13,cs (the high part can't overflow, since a*b+carry+r fits in 128 bits)
  - adds x12,x12,x14 ; cinc x13,x13,cs
  - str x12,[x4,x15,lsl 3]; mov x9,x13
- After the inner loop: r[i+nb] = x9 (this slot has only been zeroed, not otherwise written, so a plain store is right). Its index is x6+x3.

Count: k = n; while k>0 and r[k-1]==0, k--. Loop: cbz x5,done; ldr x6,[x4,x5,lsl 3] with x5-1. I use x8 = x5-1 as the index: sub x8,x5,1; ldr x6,[x4,x8,lsl 3]; cbnz x6,done; mov x5,x8; b loop. Return x5.

The nb==0 case skips to the count section. With na==0, cmp x6,x1 fails immediately, so the outer loop doesn't run.
