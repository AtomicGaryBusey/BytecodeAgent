Register plan: rbx = dst, r12 = src, r13 = n, r14 = f, r15 = i, rbp = count.

That is six pushes, an even number. At entry rsp is 8 mod 16, so six pushes make it 8 + 48 = 56 mod 16 = 8, which is misaligned. A seventh push or a `sub rsp, 8` is needed, so I use `sub rsp, 8`.

Loop body:
- rdi = [r12 + r15*8]
- call r14
- mov [rbx + r15*8], rax
- cmp rax, [r12 + r15*8]. Because dst[i] < src[i] is signed, I use setl on al and add the result to rbp. Reloading src is fine since src and dst do not overlap.
- Instead of setl, I use `jge` to skip an `inc rbp`.

`mov rdi, [mem]` needs no size, since the register implies it.
