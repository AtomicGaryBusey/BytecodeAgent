Plan: use simple repeated multiplication (k ≤ 64, n ≤ 6), with two scratch matrices in tmp.

Let N = n*n. Let T1 = tmp and T2 = tmp + N*8 bytes.

- out = identity.
- Repeat k times: T1 = out * a; copy T1 to out.
- At the end, zero all 2N elements of tmp.

This never uses square-and-multiply, so the cost is 64 multiplications of at most 216 MACs each, which is fine.

Registers:
- x0 = a, x1 = n, x2 = k, x3 = out, x4 = tmp
- x5 = N
- x6 = i, x7 = j, x8 = t, x9 = accumulator
- x10, x11 = loaded values
- x12 = address scratch
- x13 = index scratch

Init: x5 = n*n. Zero out (x13 from 0 to N: str xzr [x3, x13, lsl 3]). Then set the diagonal: for i in 0..n, out[i*(n+1)] = 1. Use x14 = n+1, x13 = 0; loop i, storing 1 at out[x13*8] and adding x14 to x13.

Multiply loop (while x2 != 0):
- i loop: x6 = 0.
- j loop: x7 = 0, x9 = 0, t loop x8 = 0.
  - x10 = out[i*n + t]: x12 = x6*n + x8 via madd, ldr x10, [x3, x12, lsl 3].
  - x11 = a[t*n + j]: x12 = madd(x8, x1, x7), ldr x11, [x0, x12, lsl 3].
  - x9 += x10*x11 (madd).
- Store to T1[i*n + j] with x12 = madd(x6, x1, x7); str x9, [x4, x12, lsl 3].
- After all loops, copy N elements from tmp to out.

Cleanup: zero 2N elements, using x13 from 0 to 2N: x14 = 2*N, loop str xzr [x4, x13, lsl 3]. Return x0 = 0.

Since k = 0 is possible, the loop check comes first. The scratch T2 is unused but is zeroed anyway.
