I'll use the bit-by-bit digit method, which cannot overflow.

Algorithm:
- res = 0, bit = 1<<62.
- Shrink bit while bit > n: bit >>= 2. This loop ends when bit is 0 (n = 0) or bit <= n.
- While bit != 0: if n >= res + bit, then n -= res + bit and res = (res>>1) + bit; else res >>= 1. Then bit >>= 2.

Overflow check: res + bit is at most about 2^32 + 2^62, which is fine. The sum res+bit is compared against n as unsigned.

Register use:
- x0 = n
- x1 = res
- x2 = bit
- x3 = temp

Code:
```
mov x1, 0
mov x2, 1<<62
shrink: cmp x2, x0
b.ls loop   (if bit <= n)
lsr x2, x2, 2
cbnz x2, shrink
loop: cbz x2, done
add x3, x1, x2
cmp x0, x3
b.lo less
sub x0, x0, x3
lsr x1, x1, 1
add x1, x1, x2
b next
less: lsr x1, x1, 1
next: lsr x2, x2, 2
b loop
done: mov x0, x1
ret
```

For n=0, bit shrinks until it reaches 0. The shrink loop compares bit with n=0: bit > 0, so it shifts, and cbnz falls through when bit is 0. Then loop hits cbz and done, returning 0. This is correct.
