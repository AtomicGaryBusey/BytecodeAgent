Use the bitwise digit-by-digit method:

```
res = 0; bit = 1<<62
while bit > n: bit >>= 2
while bit != 0:
    if n >= res + bit: n -= res + bit; res = (res >> 1) + bit
    else: res >>= 1
    bit >>= 2
```

Overflow check: res + bit is at most about 2^63 + 2^62, which fits in 64 bits.

For the first loop, clz gives the starting bit directly. If n == 0, return 0. Otherwise let lz = clz(n), then take the even value lz & ~1 and set bit = 1 << (62 - that). Since bit = 1<<62 when lz is 0 or 1, this is right. The shift amount is 62 - (lz & ~1), so bit = 1 << (62 - (lz & ~1)).

```
isqrt:
    cbz x0, .Lret
    clz x9, x0
    bic x9, x9, #1
    mov x10, #62
    sub x9, x10, x9
    mov x11, #1
    lsl x11, x11, x9
    mov x12, #0
.Lloop:
    add x13, x12, x11
    cmp x0, x13
    b.lo .Lelse
    sub x0, x0, x13
    lsr x12, x12, #1
    add x12, x12, x11
    b .Lnext
.Lelse:
    lsr x12, x12, #1
.Lnext:
    lsr x11, x11, #2
    cbnz x11, .Lloop
    mov x0, x12
.Lret:
    ret
```
