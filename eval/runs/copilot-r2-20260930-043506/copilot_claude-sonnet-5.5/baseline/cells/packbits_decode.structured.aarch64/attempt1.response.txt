Registers: x0=src, x1=n, x2=out, x3=cap. x4=i (source index), x5=o (bytes written).

Loop:
- If i >= n, return o.
- Load h = ldrsb src[i], then i++.
- If h == -128, continue.
- If h >= 0:
  - len = h+1. Need i+len <= n, otherwise return -2.
  - Copy min(len, cap-o) bytes.
  - If len > cap-o, return -1 after the partial copy.
- If h < 0:
  - len = 1-h. Need i+1 <= n, otherwise return -2.
  - Load the byte, i++, and fill min(len, cap-o) bytes.
  - If len > cap-o, return -1.

Shared code: x6 = len, x7 = remaining = cap-o, x9 = count = min(len, remaining), and x10 = flag for truncation (len > remaining).

Literal: copy loop over x9 bytes from src+i, then i += len. Because a truncated copy returns immediately, i does not matter after that.
Repeat: fill loop with the byte in w11.

Code layout:
- loop: cmp x4,x1; b.hs done; ldrsb w8,[x0,x4]; add x4,x4,#1; cmp w8,#-128 (`cmn w8,#128` compares against -128, so use cmn); b.eq loop; tbnz w8,#31,rep.
- Literal: add x6,x8,#1; add x12,x4,x6; cmp x12,x1; b.hi err2. sub x7,x3,x5; cmp x6,x7; csel x9,x6,x7,ls; mov x13,#0. Copy loop: cmp x13,x9; b.hs cdone; ldrb w14,[x0,x4]; add x4,x4,#1; strb w14,[x2,x5]; add x5,x5,#1; add x13,x13,#1; b copy. cdone: cmp x6,x7; b.hi err1; b loop. The literal copy advances x4 by the copied count, which is fine only when not truncated. In the non-truncated case x9=len, so i is correct.
- rep: neg w8,w8 gives -h in the low 32 bits; the upper bits are zeroed by the w write. Then add x6,x8,#1 gives 1-h. Check x4 < x1, otherwise err2. ldrb w11,[x0,x4]; add x4,x4,#1; sub x7,x3,x5; cmp x6,x7; csel x9,x6,x7,ls; fill loop: cbz x9,fdone; strb w11,[x2,x5]; add x5,x5,#1; sub x9,x9,#1; b fill. fdone: cmp x6,x7; b.hi err1; b loop.
- done: mov x0,x5; ret. err1: mov x0,#-1; ret. err2: mov x0,#-2; ret.

Here x7 = cap-o is always ≥ 0, because o never exceeds cap. The comparisons are unsigned and correct.
