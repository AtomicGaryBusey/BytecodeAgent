I'll use the bit-by-bit digit-by-digit method, which never overflows.

Algorithm:
- res = 0
- bit = 1<<62
- while bit > n: bit >>= 2
- while bit != 0:
  - if n >= res + bit: n -= res + bit; res = (res >> 1) + bit
  - else: res >>= 1
  - bit >>= 2
- return res

Here res + bit stays below 2^64: res is at most about 2^32 and bit at most 2^62.

Registers: rdi = n, rax = res, rcx = bit, rdx = temp.

Code:
```
mov rax, 0
mov rcx, 1<<62
loop1: cmp rcx, rdi ; jbe loop2 (bit <= n → done) ; shr rcx, 2 ; jmp loop1
```
If n = 0, bit shrinks to 0 after 31 shifts, and the loop then stops. For bit = 0 the check `cmp 0, n` gives jbe, which is taken, so it exits properly. The main loop tests bit == 0 first and finishes.

```
loop2: test rcx, rcx ; je done
lea rdx, [rax+rcx]
shr rax, 1
cmp rdi, rdx ; jb skip
sub rdi, rdx
add rax, rcx
skip: shr rcx, 2 ; jmp loop2
done: ret
```

1<<62 = 4611686018427387904.
