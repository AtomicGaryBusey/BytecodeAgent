The parse error is on line 5, which is the phi in `@loop`. QBE's phi syntax is `phi @blk, val, ...`, and every predecessor block needs an entry. My `@loop` phi listed only `@start`, `@rep` and `@litend`, and the operand order looked fine, so the likely culprit is the literal `0`. To be safe I replaced it with explicit temporaries.

Other fixes:

- `@loop` has no `@start` phi problem once `@start` jumps directly to it.
- `%i1`, `%o1`, `%j` and `%on` are defined in blocks that dominate `@litend` and `@rep`, so they are valid phi arguments.
- `ret -1` is fine in QBE.
- `%h =l sub 257, %r` is fine, and `storeb` takes the low byte of an `l` value.
- The `@rl` phi has predecessors `@body` and `@rlb`, which is correct.
- The `@sl` phi has predecessors `@lit` and `@slb`, which is correct.
- `@slb` is reached from `@sl3` and `@sl4`, and `%j2` is defined in `@slb` itself, so that is fine.
- `@cl` has predecessors `@lw` and `@clb`, which is correct.
- `%cn` is defined in `@clb`.
- `@litend` needs a phi-free jump, but `@loop` uses `%j` and `%on`, which are defined before `@litend` on every path into it.
- `%i` in the `@loop` phi is then `%j`, but `%j` is a phi in `@sl`, and it dominates `@litend` via `@slend`, so that is fine.

The `@start` block ends with `jmp @loop` directly and `@loop` follows it, and I kept the phi entries as before.

The "invalid argument" is probably from `@start` being the first block label. Other QBE programs use `@start` this way without trouble, so I suspect `phi @start, 0`, and I moved the initial values into a `@start` that defines `%z =l copy 0`.

export function l $packbits_encode(l %src, l %n, l %out, l %cap) {
@start
	%z =l copy 0
	jmp @loop
@loop
	%i =l phi @start %z, @rep %i1, @litend %j
	%o =l phi @start %z, @rep %o1, @litend %on
	%c0 =w csltl %i, %n
	jnz %c0, @body, @done
@done
	ret %o
@body
	%p =l add %src, %i
	%b =w loadub %p
	%one =l copy 1
	jmp @rl
@rl
	%r =l phi @body %one, @rlb %r2
	%k =l add %i, %r
	%c1 =w csltl %k, %n
	jnz %c1, @rl2, @rend
@rl2
	%c2 =w csltl %r, 128
	jnz %c2, @rl3, @rend
@rl3
	%q =l add %src, %k
	%bb =w loadub %q
	%c3 =w ceqw %bb, %b
	jnz %c3, @rlb, @rend
@rlb
	%r2 =l add %r, 1
	jmp @rl
@rend
	%c4 =w csltl %r, 3
	jnz %c4, @lit, @repc
@repc
	%need =l add %o, 2
	%c5 =w cslel %need, %cap
	jnz %c5, @rep, @fail
@fail
	ret -1
@rep
	%h =l sub 257, %r
	%po =l add %out, %o
	storeb %h, %po
	%po1 =l add %po, 1
	storeb %b, %po1
	%i1 =l add %i, %r
	%o1 =l add %o, 2
	jmp @loop
@lit
	jmp @sl
@sl
	%j =l phi @lit %i, @slb %j2
	%d1 =w csltl %j, %n
	jnz %d1, @sl2, @slend
@sl2
	%dd =l sub %j, %i
	%d2 =w csltl %dd, 128
	jnz %d2, @sl3, @slend
@sl3
	%j2s =l add %j, 2
	%d3 =w csltl %j2s, %n
	jnz %d3, @sl4, @slb
@sl4
	%pj =l add %src, %j
	%x0 =w loadub %pj
	%pj1 =l add %pj, 1
	%x1 =w loadub %pj1
	%pj2 =l add %pj, 2
	%x2 =w loadub %pj2
	%e1 =w ceqw %x0, %x1
	%e2 =w ceqw %x0, %x2
	%e =w and %e1, %e2
	jnz %e, @slend, @slb
@slb
	%j2 =l add %j, 1
	jmp @sl
@slend
	%L =l sub %j, %i
	%o3 =l add %o, %L
	%on =l add %o3, 1
	%c6 =w cslel %on, %cap
	jnz %c6, @lw, @fail
@lw
	%pl =l add %out, %o
	%hl =l sub %L, 1
	storeb %hl, %pl
	jmp @cl
@cl
	%cc =l phi @lw %z, @clb %cn
	%c7 =w csltl %cc, %L
	jnz %c7, @clb, @litend
@clb
	%sq =l add %src, %i
	%sq2 =l add %sq, %cc
	%v =w loadub %sq2
	%dp =l add %pl, 1
	%dp2 =l add %dp, %cc
	storeb %v, %dp2
	%cn =l add %cc, 1
	jmp @cl
@litend
	jmp @loop
}
