The error at line 8 comes from the phi syntax: QBE requires `phi @blk, val, ...`, and a bare constant like `1` is fine there. The real problem is that `@start` is followed by `jmp @check`, so the first phi is fine, but `%sm2`, `%mn2` and the others are defined later in blocks that don't dominate their uses in the way I wrote them. I've restructured so that every phi has the right predecessors.

In `@upd`, the `%mx2` phi has predecessors `@setmax` and `@nomax`, which is correct. `@mid` has predecessors `@setmin` and `@nomin`, which is also correct. The remaining problem is that `@check` references `%mn2` and `%mx2` from `@upd`, and those are defined there, so that is valid.

The likely culprit is the name `%c` or `%b`. `%f` is a valid name. The suspect is `%i`, because line 8 is `%i =l phi @start, 1, ...`, so the `phi` itself is what fails. Line 8 counts from the first line as line 1, so it is `%i =l phi`. The line numbering in the failing output is therefore consistent with the phi lines. Because `@start` has two instructions before the `jmp`, the phi's `@start` operand is correct, but QBE may require the phi's first operand to be a block label that actually precedes the phi's block. That holds here, so I can't identify the exact cause of the error.

To avoid phi problems altogether, I use stack slots instead. All state lives in `alloc8` slots in the entry block, and the loop does loads and stores.

export function l $stats_f(l %a, l %n, l %f, l %out) {
@start
	%pi =l alloc8 8
	%pmn =l alloc8 8
	%pmx =l alloc8 8
	%psm =l alloc8 8
	%pod =l alloc8 8
	%x0 =l loadl %a
	%r0 =l call %f(l %x0)
	%o0 =l and %r0, 1
	storel 1, %pi
	storel %r0, %pmn
	storel %r0, %pmx
	storel %r0, %psm
	storel %o0, %pod
	jmp @check
@check
	%i =l loadl %pi
	%c =w csltl %i, %n
	jnz %c, @body, @end
@body
	%off =l shl %i, 3
	%p =l add %a, %off
	%x =l loadl %p
	%y =l call %f(l %x)
	%mn =l loadl %pmn
	%lt =w csltl %y, %mn
	jnz %lt, @setmin, @mid
@setmin
	storel %y, %pmn
	jmp @mid
@mid
	%mx =l loadl %pmx
	%gt =w csltl %mx, %y
	jnz %gt, @setmax, @upd
@setmax
	storel %y, %pmx
	jmp @upd
@upd
	%sm =l loadl %psm
	%sm2 =l add %sm, %y
	storel %sm2, %psm
	%b =l and %y, 1
	%odd =l loadl %pod
	%odd2 =l add %odd, %b
	storel %odd2, %pod
	%i2 =l add %i, 1
	storel %i2, %pi
	jmp @check
@end
	%fmn =l loadl %pmn
	storel %fmn, %out
	%o1 =l add %out, 8
	%fmx =l loadl %pmx
	storel %fmx, %o1
	%o2 =l add %out, 16
	%fsm =l loadl %psm
	storel %fsm, %o2
	%fod =l loadl %pod
	ret %fod
}
