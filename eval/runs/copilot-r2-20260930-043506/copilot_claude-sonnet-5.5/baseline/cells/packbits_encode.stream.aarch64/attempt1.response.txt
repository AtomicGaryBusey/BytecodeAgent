Approach: a simple scalar loop.

Registers: x0=src, x1=n, x2=out, x3=cap, x4=i, x5=o (output position).

run(j), capped at 128 and bounded by n: compute k=1; while j+k<n && k<128 && src[j+k]==src[j], k++.

Main loop:
- If i>=n, return o.
- Compute run(i) in x6. If x6>=3: need o+2<=cap, else return -1. Write header 257-r as (1-r)&0xff, i.e. negate (r-1), then write the byte, o+=2, i+=r.
- Else literal: j=i; loop while j<n && j-i<128 && run(j)<3. Run check at j: b=src[j]; if j+1>=n then run<3; if src[j+1]!=b then run<3; if j+2>=n then run<3; if src[j+2]!=b then run<3; otherwise run>=3, stop. The literal always has at least 1 byte, since run(i)<3 means j=i passes. L=j-i; need o+1+L<=cap. Write header L-1, copy bytes, and set i=j.

Run computation for the first case, inline:
- x7=src[i], x6=1, x8=i+1.
- Loop: if x8>=n break; if x6>=128 break; load src[x8]; if != x7 break; x6++, x8++.

Literal loop, with x6=j:
- Loop: if j>=n, end; if j-i>=128, end; check as above; j++.
- Checks: x9=j+1; if x9>=n goto ok (continue); ldrb w10,[x0,x9]; ldrb w11,[x0,j]; if not equal goto ok; x9=j+2; if x9>=n goto ok; ldrb w10,[x0,x9]; if equal goto end; ok: j++.

Copy loop: x12=i, x13=o+1 as the destination; copy while x12<j.
