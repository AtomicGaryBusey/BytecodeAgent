The bug is in the loop's load. It post-increments by 8 (`disp: 8`), but the first load already advanced the pointer by 8 with `disp: 0, writeback: post`. The `disp: 0` is encoded as a post-increment of 0, so the pointer never moved after the first element. The second element therefore reloaded a[0], which matches the wrong results.

The fix is to use `disp: 8` on the first load as well.

The loop's post-index load of 8 was already correct. The expected results confirm this, since a=[2,4,6] gives max 19 against our 13.
