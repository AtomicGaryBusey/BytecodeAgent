mp_mul: schoolbook multiplication. Arguments: rdi=a, rsi=na, rdx=b, rcx=nb, r8=r.

Plan:
- If na==0 or nb==0, return 0 (nothing to write, since na+nb limbs may still be nonzero when only one is 0). If na=0 and nb=3, r[0..2] must be written as zeros. So zero-fill r[0..na+nb-1] first, then return 0 if either is zero.
- Zero r for na+nb limbs, then for each i in a: carry=0; for each j in b: compute a[i]*b[j] + r[i+j] + carry into 128 bits; store the low half, and the high half becomes the carry. After the inner loop, r[i+nb] = carry (it was zero).
- The 128-bit sum cannot overflow: (2^64-1)^2 + 2(2^64-1) = 2^128-1.

Registers: rdi=a, rsi=na, r9=b (moved from rdx, since mul clobbers rdx), rcx=nb, r8=r. r10 = i, r11 = j, rbx is saved and holds the carry, and a[i] is reloaded from memory each iteration.

Code:
- Zero fill: rax = na+nb; loop k from 0 while k<rax, storing 0 to r[k].
- Outer: r10=0; while r10<na: rbx=0 (carry); r11=0; inner: rax=a[r10]; mul qword ptr [r9+r11*8] gives rdx:rax; lea r-index = r10+r11 in rsi? rsi is na and is needed, so use rax/rdx carefully with an extra register (r10+r11 goes in a temp, rbp, saved). Then add rax, [r8+rbp*8]; adc rdx,0; add rax, rbx; adc rdx,0; store rax; rbx=rdx.
- After the inner loop: r[r10+nb] = rbx.
- Final: k = na+nb; while k>0 and r[k-1]==0, decrement k. Return k.

mp_mul:
    push rbx
    push rbp
    mov r9, rdx
    lea rax, [rsi + rcx]
    xor edx, edx
.Lz:
    cmp rdx, rax
    jge .Lzd
    mov qword ptr [r8 + rdx*8], 0
    inc rdx
    jmp .Lz
.Lzd:
    test rsi, rsi
    jz .Lzero
    test rcx, rcx
    jz .Lzero
    xor r10d, r10d
.Louter:
    cmp r10, rsi
    jge .Lfin
    xor ebx, ebx
    xor r11d, r11d
.Linner:
    cmp r11, rcx
    jge .Lind
    mov rax, qword ptr [rdi + r10*8]
    mul qword ptr [r9 + r11*8]
    lea rbp, [r10 + r11]
    add rax, qword ptr [r8 + rbp*8]
    adc rdx, 0
    add rax, rbx
    adc rdx, 0
    mov qword ptr [r8 + rbp*8], rax
    mov rbx, rdx
    inc r11
    jmp .Linner
.Lind:
    lea rbp, [r10 + rcx]
    mov qword ptr [r8 + rbp*8], rbx
    inc r10
    jmp .Louter
.Lfin:
    lea rax, [rsi + rcx]
.Ltrim:
    test rax, rax
    jz .Lret
    cmp qword ptr [r8 + rax*8 - 8], 0
    jne .Lret
    dec rax
    jmp .Ltrim
.Lzero:
    xor eax, eax
.Lret:
    pop rbp
    pop rbx
    ret
