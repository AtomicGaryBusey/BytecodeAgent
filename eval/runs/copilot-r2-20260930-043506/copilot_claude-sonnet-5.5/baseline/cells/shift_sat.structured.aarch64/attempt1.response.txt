Approach: AArch64 register shifts use n mod 64, so n >= 64 needs explicit handling.

- Compute the left shift with `lsl x2, x0, x1`, then `cmp x1, #64` and `csel x2, x2, xzr, lo` (0 when n >= 64).
- For the arithmetic right shift, clamp n to 63 with `mov x3, #63`, `cmp x1, x3`, `csel x3, x1, x3, lo`, then `asr x4, x0, x3`. This gives the sign fill for n >= 64.
- Add the two results: `add x0, x2, x4`.

The `cmp x1, #64` flags are overwritten by the second compare, but by then the left-shift `csel` has already consumed them.
