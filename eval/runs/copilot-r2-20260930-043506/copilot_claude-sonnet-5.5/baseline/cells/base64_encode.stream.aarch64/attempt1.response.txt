Scalar implementation: process 3-byte groups, with a per-character mapping done by arithmetic.

Mapping of v (0..63) to a character: start with v+65. If v>=26 add 6 (giving 97..). If v>=52 subtract 75 (gives 48..). If v==62 the char is '+' (43), if v==63 it is '/' (47). Use csel with compares, in a macro-like sequence per character.

Helper sequence for value in w9 → char in w9, using w10 and w11 as temps:
- add w10, w9, #65
- cmp w9, #26; add w11, w10, #6; csel w10, w11, w10, hs
- cmp w9, #52; sub w11, w10, #75; csel w10, w11, w10, hs
- cmp w9, #62; mov w11, #43; csel w10, w11, w10, eq
- cmp w9, #63; mov w11, #47; csel w10, w11, w10, eq

Check: v=52: 52+65=117, +6=123, -75=48 ✓. v=62: replaced by '+'. v=63: '/'.

Since the sequence is repeated, I use a loop over 4 characters. Structure: form the 24-bit value in w12 (for the tail, missing bytes are zero). Then for k=0..3, extract (w12 >> (18-6k)) & 63, map, and store. For the tail, the characters beyond the valid count are replaced by '='.

Registers: x0 src, x1 n, x2 out, x3 = start of out (for the return value). Loop while remaining >= 3: load 3 bytes, encode 4 chars via the inner loop (x13 = shift, starting at 18, decreasing by 6 down to 0).

Tail: rem = n - processed. If rem==0 finish. If rem==1: w12 = b0<<16, chars=2. If rem==2: w12 = b0<<16|b1<<8, chars=3. Encode 4 chars, with index k >= chars written as '='. Handle this by having the encode loop take a limit count in w14 (4 for full groups): for k in 0..3, if k<w14 map, else '='.
