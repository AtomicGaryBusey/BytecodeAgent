Use the bitwise digit-by-digit method, which never overflows:

```
res = 0; bit = 1<<62
while bit > n: bit >>= 2
while bit != 0:
  if n >= res + bit: n -= res + bit; res = (res>>1) + bit
  else: res >>= 1
  bit >>= 2
```

res + bit stays at most about 2^63 + 2^62, so it fits in 64 bits. All comparisons are unsigned.

The first loop is folded into the main loop: while bit is greater than n, the else branch does res >>= 1 with res = 0, which changes nothing. So the main loop can start at bit = 1<<62 directly.

```
export function l $isqrt(l %n) {
@start
	jmp @loop
@loop
	%bit =l phi @start 4611686018427387904, @next %bit2
	%res =l phi @start 0, @next %res2
	%n1 =l phi @start %n, @next %n2
	%t =l add %res, %bit
	%c =w culel %t, %n1
	jnz %c, @yes, @no
@yes
	%na =l sub %n1, %t
	%rh =l shr %res, 1
	%ra =l add %rh, %bit
	jmp @next
@no
	%rb =l shr %res, 1
	jmp @next
@next
	%n2 =l phi @yes %na, @no %n1
	%res2 =l phi @yes %ra, @no %rb
	%bit2 =l shr %bit, 2
	%z =w ceql %bit2, 0
	jnz %z, @done, @loop
@done
	ret %res2
}
```
