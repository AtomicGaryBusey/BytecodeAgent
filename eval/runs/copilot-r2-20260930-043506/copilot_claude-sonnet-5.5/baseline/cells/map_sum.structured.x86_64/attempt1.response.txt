Register plan: rbx = pointer, r12 = remaining count, r13 = function pointer, r14 = accumulator.

Alignment: at entry rsp is 8 mod 16. Four pushes (rbx, r12, r13, r14) add 32 bytes, leaving rsp still 8 mod 16, so one more `sub rsp, 8` brings it to 0 mod 16. Alternatively, push five registers (odd count) and use r15 as well. I use five pushes: rbx, r12, r13, r14, r15. Five pushes is 40 bytes, and 8 + 40 = 48, which is 0 mod 16, so rsp is aligned at each call.

The loop checks n first, so n = 0 returns 0. Each iteration loads `a[i]` into rdi, calls f, and adds rax to r14. Then it advances the pointer and decrements the count.
