Design: rsi = n, rdi = src, rdx = out, rcx = cap. Use r8 = src index i, r9 = output count o.

Loop:
- if i >= n: return o.
- h = movsx r10d, byte [rdi+i]; i++.
- if h == -128: continue.
- if h >= 0: len = h+1. Need i+len <= n, else return -2. Then copy min(len, cap-o) bytes. If len > cap-o, copy cap-o bytes, o = cap, return -1. Otherwise o += len.
- if h < 0: len = 1-h. Need i+1 <= n, else -2. Byte b = src[i], i++. Fill min(len, cap-o) bytes; overflow check the same way.

The cap-o remainder is in r11. For a literal, compute the count in rax = len; if rax > r11, set the flag in bl (a callee-saved register I avoid by using r10 instead) and clamp.

Registers: rax = len, r10 = h, r11 = remaining, rcx = cap, rsi = n. The copy loop needs a counter and a byte register, so I use ebx-free scratch: rax as the counter for the copy, and a separate overflow flag kept in memory-free form, since after the copy I can recompute overflow by testing whether o == cap and the original len exceeded. Simpler: store the original len in r10 (h no longer needed after computing len), and set r11 = cap - o. If r10 > r11: rax = r11 and the overflow path is taken, else rax = r10.

Copy literal: loop with a counter and offset, using the byte register in rdi-free scratch: r11 is reused as the temp byte. Take the count in rax and the copy index in a register such as rsi... which holds n. I use r9 as the output position directly: each byte is written to [rdx+r9], r9++, i++. After the copy, on overflow, r9 == cap, so return -1.

Literal copy loop: while rax != 0: load r11b = [rdi+r8]; store [rdx+r9]; inc r8; inc r9; dec rax. On overflow the source index no longer matters. Repeat: load the byte to r11b before the loop, but r11 held the remaining count, so by then I have already computed rax. Fine.

The overflow flag is r10 > remaining, recomputed before the copy, and I need it after the copy. I keep it by re-checking after the loop: for overflow, r9 == cap and the original len exceeded. Non-overflow could also end with r9 == cap (exact fit), which is fine and not an error. So I store the overflow flag in a stack slot: push and pop is not needed, since I can use the red zone at [rsp-8] (leaf function, allowed).
