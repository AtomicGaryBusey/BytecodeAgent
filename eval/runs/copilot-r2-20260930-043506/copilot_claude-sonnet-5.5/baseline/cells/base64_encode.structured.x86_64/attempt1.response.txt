Plan: write a helper macro-like sequence, since there are no subroutines to reuse. I'll use a call-free design: a loop that emits one character from the 6-bit value in eax via arithmetic, expanded inline four times per group.

Character mapping for v in eax, result in dl (using ecx as scratch):
- lea edx,[rax+65]
- cmp eax,26; jb done, add edx,6 (to 'a'-26 → 97-26=71, and 71-65=6)
- cmp eax,52; jb done, sub edx,75 (52 → '0'=48: 48-52 = -4, and -4-65 = -69 → relative to the +71 base: 71+x = -4 → x=-75)
- cmp eax,62; jb done, add edx,-(48-52)+43-62...

Instead, use a branchless cascade with cmov to keep the code short: edx = v+65; then for each threshold add a delta: v>=26: +6; v>=52: -75; v>=62: '+'(43) vs 62+(-4)=58 → -15; v>=63: '/'(47) vs 63-4=59 → -12... check: v=62 → 43, v+65+6-75 = v-4 = 58, so delta -15 gives 43. v=63: 63-4-15 = 44, need 47, so +3. I'll implement it with cmp/jb branches, which is simpler.

The output routine is a sequence expanded per character, with a distinct label each time. To avoid many copies, I use a loop over the 4 characters of a group instead:
- Registers: rdi=src, rsi=n remaining, r8=out, r9=out start.
- Each group: load bytes into r10d (the 24-bit value), with the count of bytes in r11. For a partial group, load only the available bytes.
- Emit 4 chars: ecx=18,12,6,0 shifts. For chars beyond the byte count+1, write '='.

Group loop: r11=min(rsi,3). Build r10d = b0<<16 | (b1<<8 if r11>=2) | (b2 if r11>=3). Then for i in 0..3: if i > r11 emit '=' else map. Char count valid = r11+1. The loop counter is r6 (rbx, saved), which holds the shift, starting at 18 and decreasing by 6 down to 0; the index i is derived from the counter, and r11+1 chars are mapped, tracked by r11 decrementing: the "remaining valid" count is in r11d+1, which I decrement per char.
