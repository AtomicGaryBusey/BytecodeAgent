Design: x0=code, x1=len, x2=stack base, x3=cap. Registers: x4=pc, x5=sp pointer (the address of the next free slot), x6=opcode, x7 scratch.

Startup: zero the whole stack buffer first, so the final buffer holds zeros beyond depth d.

Loop (top):
- if pc >= len (cmp x4,x1; b.ge done). pc is never negative, so b.hs works.
- load op = code[pc].
- dispatch with a compare chain.

Ops:
- 0: done.
- 1: ldr x7,[x0,x4,lsl 3 + 8]. Add 1 to the index first: add x8,x4,#1; ldr x7,[x0,x8,lsl 3]; str x7,[x5],#8; pc+=2.
- 2, 3, 4: ldp is awkward here, so use ldr x8,[x5,#-8]; ldr x9,[x5,#-16]; sub x5,x5,#8; compute; str x, [x5,#-8]. Here a=x9, b=x8.
- 5: ldr x8,[x5,#-8]; str x8,[x5],#8.
- 6: swap the two entries in place.
- 7: sub x5,x5,#8. The popped slot must be zeroed at the end. Because I zero the whole buffer at the start, popped slots would hold stale values. So when popping I must store 0 to the vacated slot. Simpler: at done, zero from x5 to the end of the buffer (x2+cap*8). Then the initial zeroing is unnecessary; only the final clear is needed.
- 8: ldr x8,[x5,#-16]; str x8,[x5],#8.
- 9: cmp x9,x8; cset x9,lt; store at [x5,#-8] after the pop.
- 10: pop v; if v==0, pc=code[pc+1], else pc+=2.
- 11: pc=code[pc+1].

Done: compute the return value: if x5==x2 then x0=0, else ldr x0,[x5,#-8]. Then clear the loop: end = x2+cap*8; while x5<end: str xzr,[x5],#8.

Dispatch: the opcode is in x6. Use cbz for 0, then cmp #n with b.eq for the rest. Every path ends with b loop, and the pc increments happen in each handler.
