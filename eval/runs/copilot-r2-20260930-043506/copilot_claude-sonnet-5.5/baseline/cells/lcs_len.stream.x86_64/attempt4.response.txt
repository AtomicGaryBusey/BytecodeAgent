Register plan: rdi=x, rsi=m, rdx=y, rcx=n, r8=row.

- r9 = j
- r10 = i
- r11 = x[i]
- rax = diag
- rsi = m (kept)
- rdi = x (kept)
- rcx = n (kept)
- r8 = row
- r9 = j
- rdx = y

The inner loop needs these temporaries: up, the y byte, and the left value row[j-1]. Free registers are r10, r11, rax, r9, plus rsi/rdi held in place. I'll use rbx for the diag, saving and restoring it.

Inner loop, with j from 1 to n:
- up = row[j] (into rbx's neighbour, see below)
- if x[i] == y[j-1], then new = diag + 1
- else new = max(row[j], row[j-1])
- diag = up

The registers are:
- r10 = i
- r11b = x[i]
- rax = diag
- r9 = j
- rbx = up (saved)
- rsi = temporary, since m is compared against i only in the outer loop. Instead I keep m in r12 (saved), which frees rsi.

Callee-saved registers used: rbx, r12. Two pushes leave rsp aligned, which is fine since there are no calls.

Code:
- Zero row[0..n].
- Outer loop over i.
- Inner loop over j.
- Return row[n].

Inner loop details:
- `mov rbx, [r8+r9*8]` loads up.
- `movzx esi, byte ptr [rdx+r9-1]` loads the y byte.
- `cmp esi, r11d` compares it with x[i].
- If equal, `lea rsi, [rax+1]`.
- Otherwise `mov rsi, rbx`, then `cmp rsi, [r8+r9*8-8]`, then `cmovl rsi, [r8+r9*8-8]`.
- Then `mov [r8+r9*8], rsi`, `mov rax, rbx`, `inc r9`.

row[j-1] has already been updated for this row, as the recurrence requires.

```
lcs_len:
    push rbx
    push r12
    mov r12, rsi
    xor r9d, r9d
.Lzero:
    cmp r9, rcx
    jg .Lzdone
    mov qword ptr [r8 + r9*8], 0
    inc r9
    jmp .Lzero
.Lzdone:
    xor r10d, r10d
.Louter:
    cmp r10, r12
    jge .Ldone
    movzx r11d, byte ptr [rdi + r10]
    xor eax, eax
    mov r9d, 1
.Linner:
    cmp r9, rcx
    jg .Lnext
    mov rbx, qword ptr [r8 + r9*8]
    movzx esi, byte ptr [rdx + r9 - 1]
    cmp esi, r11d
    jne .Lne
    lea rsi, [rax + 1]
    jmp .Lstore
.Lne:
    mov rsi, rbx
    cmp rsi, qword ptr [r8 + r9*8 - 8]
    cmovl rsi, qword ptr [r8 + r9*8 - 8]
.Lstore:
    mov qword ptr [r8 + r9*8], rsi
    mov rax, rbx
    inc r9
    jmp .Linner
.Lnext:
    inc r10
    jmp .Louter
.Ldone:
    mov rax, qword ptr [r8 + rcx*8]
    pop r12
    pop rbx
    ret
```
