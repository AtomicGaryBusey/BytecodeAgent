Register mapping at entry: rdi=x, rsi=m, rdx=y, rcx=n, r8=row.

- r9 is the outer index i.
- r10 is x[i].
- r11 is diag.
- rax is j.
- rdx stays as the y pointer.
- rsi stays as m.
- rdi stays as x.
- r8 is row.
- rcx is n.
- The scratch registers are r8, r9 and r10 plus others, so I use rbx sparingly and avoid it.

Inner loop, with j from 1 to n, where y[j-1] is at [rdx+rax-1]:
- up = row[j], loaded into rbx-free scratch r9?

r9 is taken by the outer index, so I use these scratch registers:
- `up` goes in rsi? No, rsi holds m. I use an extra register instead: push rbx and use it for up.
- Also push r12 to hold row[j-1], which is the new value of the previous cell.

Inner body:
```
mov rbx, [r8+rax*8]        # up
cmp r10b, [rdx+rax-1]
jne .Lne
lea r12, [r11+1]
jmp .Lst
.Lne:
mov r12, rbx
cmp r12, [r8+rax*8-8]
cmovl r12, [r8+rax*8-8]
.Lst:
mov [r8+rax*8], r12
mov r11, rbx
inc rax
```
For the max, row[j-1] has already been updated for this i, which is correct. The result is row[n], which I return in rax at the end. Two pushes keep the stack aligned in effect, and there are no calls anyway.

lcs_len:
    push rbx
    push r12
    xor eax, eax
.Lz:
    cmp rax, rcx
    jg .Lzd
    mov qword ptr [r8 + rax*8], 0
    inc rax
    jmp .Lz
.Lzd:
    xor r9d, r9d
.Louter:
    cmp r9, rsi
    jge .Ldone
    movzx r10d, byte ptr [rdi + r9]
    xor r11d, r11d
    mov eax, 1
.Linner:
    cmp rax, rcx
    jg .Lnext
    mov rbx, qword ptr [r8 + rax*8]
    cmp r10b, byte ptr [rdx + rax - 1]
    jne .Lne
    lea r12, [r11 + 1]
    jmp .Lst
.Lne:
    mov r12, rbx
    cmp r12, qword ptr [r8 + rax*8 - 8]
    cmovl r12, qword ptr [r8 + rax*8 - 8]
.Lst:
    mov qword ptr [r8 + rax*8], r12
    mov r11, rbx
    inc rax
    jmp .Linner
.Lnext:
    inc r9
    jmp .Louter
.Ldone:
    mov rax, qword ptr [r8 + rcx*8]
    pop r12
    pop rbx
    ret
