Register plan: x0=x, x1=m, x2=y, x3=n, x4=row. Scratch: x5=i, x6=j, x7=diag, x9=x[i], x10=up, x11=y[j-1], x12=row[j-1] (the new left value), x13=address.

Zero row[0..n]: loop k from 0 to n inclusive.

Outer loop, for each i:
- load x9 = x[i] and set diag = 0
- x12 = row[0] = 0 (the left value)
- inner loop j = 1..n:
  - up = row[j]
  - y[j-1] is at y + j - 1, loaded with the register-index form using x6 and disp -1. The index form has no displacement, so I keep a pointer to y that is decremented by 1 (x14 = y - 1) and index with x6.
  - if equal, new = diag + 1; otherwise new = max(up, left).
  - store row[j] = new, set diag = up, left = new.

The row address is x4 + x6*8, which the indexed form handles with scale 8.

Inner body:
```
ldr x10,[x4,x6,lsl3]
ldrb w11,[x14,x6]
add x15,x7,#1
cmp x10,x12
csel x13,x10,x12,gt

mov x7,x10
mov x12,x13

cmp x6,x3
b.le inner
```
The inner loop must be skipped when n=0, so I check n==0 before entering it. If n=0 the row is only row[0]=0 and the result is 0. The inner loop is entered with x6=1 and runs while x6<=n.

The result is row[n], loaded at the end.
