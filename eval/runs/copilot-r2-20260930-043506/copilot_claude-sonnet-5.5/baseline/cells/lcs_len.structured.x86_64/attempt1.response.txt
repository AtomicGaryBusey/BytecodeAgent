Register plan: rdi=x, rsi=m, rdx=y, rcx=n, r8=row. Scratch: rax, r9, r10, r11, plus r8 (row) and rcx (n) kept as they are.

Zero row[0..n]:
- xor eax,eax; r9=0; loop while r9<=n: row[r9]=0.

Outer loop, with i in r10 (compare against m):
- load bl? rbx is callee-saved, so use r11 for x[i] instead: movzx r11d, byte [rdi+r10].
- diag in rax = 0; j in r9 = 1.
- inner loop, while j<=n:
  - up = row[j] in rsi? rsi holds m, so keep m in a different register. Push rbx and use rbx=m instead.
  - Use rdx for y, and rsi for up (after moving m to rbx).
  - up (rsi) = row[j]
  - cmp r11b, byte [rdx+r9-1]
  - jne to the max path
  - else new = rax+1
  - max path: new = row[j] (rsi), compare with row[j-1] and take the larger (cmovl)
  - row[j] = new, diag (rax) = up (rsi), j++

Result is row[n], returned in rax at the end.

Since rsi is used for up, I save m in rbx.

Code steps for the inner loop:
- mov rsi,[r8+r9*8]
- movzx ebp?, no: use a memory compare, `cmp r11b, [rdx+r9-1]` with size 1 implied by the register.
- jne .ne
- lea rax,[rax+1]; jmp .store
- .ne: mov rax,[r8+r9*8-8]; cmp rax,rsi; cmovl rax,rsi
- .store: mov [r8+r9*8],rax. But diag must become the old up, which is rsi, and rax is the new value. So after the store, mov rax,rsi.

In the match case rax holds diag, so the new value is rax+1. Correct.

Loop ends: inc r9; cmp r9,rcx; jle inner. If n=0 the inner loop must be skipped, so check r9>rcx before entering it (a `jg` to the outer-loop increment).
