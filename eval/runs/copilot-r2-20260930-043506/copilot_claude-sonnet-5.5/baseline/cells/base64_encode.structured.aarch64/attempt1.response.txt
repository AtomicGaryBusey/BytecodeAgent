Plan: a helper sequence that maps a 6-bit value to a character, inlined for each of 4 output chars using csel-based arithmetic.

Mapping for v in w-register:
- Start with c = v + 65.
- If v >= 26: c = v + 71 (97-26).
- If v >= 52: c = v - 4 (48-52).
- If v == 62: '+' (43).
- If v == 63: '/' (47).

Implementation per character (input w9 = index, result w9), using scratch w10 and w11:
- add w10, w9, #65
- cmp w9, #26; add w11, w9, #71; csel w10, w11, w10, hs
- cmp w9, #52; sub w11, w9, #4; csel w10, w11, w10, hs
- cmp w9, #62; mov w11, #43; csel w10, w11, w10, eq
- cmp w9, #63; mov w11, #47; csel w10, w11, w10, eq

I'll write a full group of 3 bytes as: w9 = b0<<16 | b1<<8 | b2. Extract each index into w12 and map it. The main loop runs while n >= 3. The tail handles n = 1 or 2 by building the value with missing bytes as zero, emitting 2 or 3 chars and then padding.

Registers: x0 src, x1 n, x2 out, x3 = start of out (for the return value, computed as the difference). The mapping is repeated inline via a macro-like expansion. To keep the output smaller, I use a subroutine-less approach: a shared "emit4" block that takes the 24-bit value in w4 and writes 4 chars at x2 without advancing it. The tail then overwrites the padding chars with '='. The block is entered via a loop with a flag: the tail sets the flag x5=1 and returns to the epilogue.

Structure:
- x3 = x2 saved.
- loop: if x1 < 3 goto tail; load 3 bytes, post-incrementing x0; form w4; call the block (inline via the loop only, with the tail jumping back into it).
- Block: emit 4 chars (x2 += 4), then if x5 != 0 goto fix; otherwise x1 -= 3 and branch to loop.
- Tail: if x1 == 0 goto done. Load b0; if x1 == 2 load b1 else 0; w4 = b0<<16 | b1<<8; x5 = x1; b to block.
- fix: x2 was advanced by 4. If x5 == 1, store '=' at [x2,-2] and [x2,-1]; else store at [x2,-1].
- done: x0 = x2 - x3.

Since x5 is 0 in the main loop, the block distinguishes the cases correctly.
