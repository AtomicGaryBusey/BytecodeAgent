Compute n*(n+1)/2 for n > 0, otherwise 0.

```
lea rax,[rdi+1]       48 8d 47 01
imul rax,rdi          48 0f af c7
sar rax,1             48 d1 f8
test rdi,rdi          48 85 ff
cmovle rax,zero       needs a zero register
```

Use xor edx,edx first (31 d2), then cmovle rax,rdx (48 0f 4e c2). xor changes the flags, so it must come before the test.

For n <= 0 the cmov selects 0. Because n <= 1000, there is no overflow.

Sequence:
- 31 d2: xor edx,edx
- 48 8d 47 01: lea rax,[rdi+1]
- 48 0f af c7: imul rax,rdi
- 48 d1 f8: sar rax,1
- 48 85 ff: test rdi,rdi
- 48 0f 4e c2: cmovle rax,rdx
- c3: ret
