Approach: two pointers, `rdi` pointing at the start and `rax` at the last element. Swap while `rdi < rax`.

```
lea rax, [rdi+rsi*8-8]   ; 48 8d 44 f7 f8
loop:
cmp rdi, rax             ; 48 39 c7
jae done                 ; 73 0f
mov rcx,[rdi]            ; 48 8b 0f
mov rdx,[rax]            ; 48 8b 10
mov [rdi],rdx            ; 48 89 17
mov [rax],rcx            ; 48 89 08
add rdi,8                ; 48 83 c7 08
sub rax,8                ; 48 83 e8 08
jmp loop                 ; eb e7
done:
xor eax,eax              ; 31 c0
ret                      ; c3
```

Byte sizes after the loop label: cmp 3, jae 2, mov 3, mov 3, mov 3, mov 3, add 4, sub 4, jmp 2. Total from the jae end: 3+3+3+3+4+4+2 = 22 = 0x16, so jae is `73 16`. The jmp end is at 3+2+22 = 27 bytes after the loop start, so the displacement is -27 = 0xe5.

For n=0, rax = a-8 < rdi, so it exits immediately. The comparison is unsigned and the pointers are fine.
