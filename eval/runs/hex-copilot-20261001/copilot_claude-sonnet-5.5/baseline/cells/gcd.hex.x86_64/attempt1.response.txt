Euclid's algorithm with `div`:

```
loop:
  test rsi, rsi
  jz done
  mov rax, rdi
  xor edx, edx
  div rsi
  mov rdi, rsi
  mov rsi, rdx
  jmp loop
done:
  mov rax, rdi
  ret
```
