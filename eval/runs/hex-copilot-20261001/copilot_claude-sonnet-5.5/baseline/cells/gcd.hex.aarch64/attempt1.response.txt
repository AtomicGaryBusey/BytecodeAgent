Euclid's algorithm in a loop:

```
loop: cbz x1, done
      udiv x2, x0, x1
      msub x2, x2, x1, x0   // x2 = x0 - x2*x1
      mov x0, x1
      mov x1, x2
      b loop
done: ret
```

Encodings:
- cbz x1, done: the cbz is at offset 0 and ret at offset 24, so imm19 = 6. The word is 0xB4000000 | (6<<5) | 1 = 0xB40000C1.
- udiv x2, x0, x1: 0x9AC10802.
- msub x2, x2, x1, x0: 0x9B018042. Here Rm=x1 (bits 20-16 = 1), Ra=x0 (bits 14-10 = 0, with o0=1 at bit 15), Rn=x2, Rd=x2. So 0x9B000000 | (1<<16) | (1<<15) | (0<<10) | (2<<5) | 2 = 0x9B018042.
- mov x0, x1: orr x0, xzr, x1 = 0xAA0103E0.
- mov x1, x2: 0xAA0203E1.
- b loop: at offset 20, target 0, so offset -20 /4 = -5. imm26 = 0x3FFFFFB, giving 0x17FFFFFB.
- ret: D65F03C0.
