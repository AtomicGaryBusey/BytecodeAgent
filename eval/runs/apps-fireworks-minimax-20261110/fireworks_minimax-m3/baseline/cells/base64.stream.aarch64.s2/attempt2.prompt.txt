Every other general-purpose register (x0-x30) is zero; x30 is not a return address, so `_start` must never return with `ret`; the program ends only through the exit system call.

System calls: the `svc #0` instruction, with the system call number in x8 and the arguments in x0, x1, x2; the result comes back in x0. Every other register is preserved. Exactly these four are available:

- write = 64: write(fd, buf, count) with fd 1 (standard output) or 2 (standard error); returns count.
- exit = 93: exit(status) ends the program; the exit status is the low 8 bits of status.
- exit_group = 94: the same as exit.
Any other system call number or file descriptor stops the program with an error, and so does a buffer that is not entirely inside the program's memory.
