Signed overflow happens when a and b have the same sign and the sum's sign differs. Equivalently, `((a^s) & (b^s)) < 0`, where `s` is the wrapped sum.


export function l $add_overflow(l %a, l %b, l %out) {
@start
	%s =l add %a, %b
	storel %s, %out
	%x =l xor %a, %s
	%y =l xor %b, %s
	%z =l and %x, %y
	%r =l shr %z, 63
	ret %r
}

Note: `shr` on `l` is an arithmetic shift in QBE only for signed use. It is a logical shift here, so it yields 0 or 1.

Correction: QBE's `shr` is arithmetic and `shl` is logical, and `sar` doesn't exist in QBE, so I should use `shr` with care. QBE's `shr` performs an arithmetic shift on signed values only when defined that way, which means the result may be -1 rather than 1. The safe version is below.

export function l $add_overflow(l %a, l %b, l %out) {
@start
	%s =l add %a, %b
	storel %s, %out
	%x =l xor %a, %s
	%y =l xor %b, %s
	%z =l and %x, %y
	%w =w csltl %z, 0
	%r =l extuw %w
	ret %r
}
